# AirPlay Windows v0.5.0 — Live FaceSwap and a multilingual interface

## Highlights

- **Live FaceSwap (experimental).** Use a local photo to replace the largest face in the AirPlay mirroring preview. The app offers NVIDIA CUDA, DirectML and CPU processing. MP4 recordings retain the original video.
- **Setup in the app.** Prepare an isolated Python environment, download and verify the models you choose, then select a source photo. Use **Preview Settings** to open an independent live preview window while changing settings.
- **Recommended defaults.** HyperSwap 1A 256, SCRFD 10G, HRFFA 68 landmarks and five-point FaceFusion-style alignment. BiSeNet and XSeg masks are off by default. When TensorRT is selected, the default compilation level is 5. The first engine build can take 5–20 minutes.
- **Ten interface languages and two themes.** English, French, Simplified Chinese, Spanish, Brazilian Portuguese, German, Japanese, Italian, Russian and Korean. Use the moon/sun button to switch between light and dark.
- **Improved experimental HLS playback.** Enable direct playback in Settings. The receiver selects a stream up to 1080p with the matching audio track.
- **Windows desktop integration.** Windows media controls support compatible AirPlay senders. The receiver can run in the notification area.

## Installation

Extract the Windows x64 ZIP and run `airplay-windows.exe` with its companion DLLs in the same directory. Python and model weights are downloaded separately when you set up FaceSwap. See the [FaceSwap guide](https://github.com/moieric11/AirPlay-Windows/blob/v0.5.0/docs/FACE_SWAP.md) for backend requirements and model options.
